Aprende a despejar x

despejar es dejar la x sola, para descubrir cuanto vale

1.¿Qué es una incógnita?

Es un número que todavía no conocemos. Lo escribimos con una letra, casi siempre x

x + 3 = 7

¿Qué número más 3 da 7? Es el 4, así que x = 4. Cuando la ecuación se complica, ya no se adivina: se despeja con un método.

2.La regla principal

La ecuación es como una balanza. Si haces algo de un lado del =, haz lo mismo del otro lado. Así sigue equilibrada.

    x + 3 = 7


    -3 -3


    x = 4 .


    Restamos 3 en los dos lados y la x quedó sola

3.¿Qué hago con lo que veo?

Para quitar algo de junto a la x, haces la operación contraria.

x + 5 → Resta 5 en los dos lados

x − 5 → Suma 5 en los dos lados

3x → Divide entre 3 en los dos lados

4. Un ejemplo completo

2x + 3 = 11

Esta es la ecuación. Queremos dejar la x sola.

2x + 3 = 11

Esta es la ecuación. Queremos dejar la x sola

2x = 8

Primero quitamos el + 3. Para eso restamos 3 en los dos lados.

2x + 3 = 11

Esta es la ecuación. Queremos dejar la x sola.

2x = 8

Primero quitamos el + 3. Para eso restamos 3 en los dos lados.

x = 4

Ahora la x está multiplicada por 2. Para quitarlo, dividimos los dos lados entre 2.

Comprobación: 2 · 4 + 3 = 11 ✓

Cambiamos la x por 4 en la ecuación original. Los dos lados valen lo mismo, así que está bien.
